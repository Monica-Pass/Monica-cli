CONNECTION · 连接
保存服务凭据，例如 work-github。用 connections、show 查看。
GRANT · 授权
限定 AI 的范围、操作和时长，例如 review-agent。用 status 查看。
BROKER · 代理
serve 启动的调用通道。默认 5 分钟，可显式设置时长；Tiga 和授权有效期独立生效。
01 / 人来操作

先配置，再启动

  1. 创建连接与同名只读授权
    monica add work-github --repo your-org/repo
  2. 配置 AI 客户端（这里选 Codex）
    monica mcp-config work-github --install codex
  3. 启动代理，保持这个终端打开
    monica serve
  4. 在另一个终端验证通道
    monica check work-github

使用自定义 --config 时，每一步和另一个终端都沿用同一路径。check 验证代理通道，AI 客户端仍需加载配置。

连接和授权可以不同名

在已有连接 work-github 上创建另一份授权：

monica grant review-agent --connection work-github --repo your-org/repo
monica next --grant review-agent

之后用 mcp-config review-agent、check review-agent、renew review-agent。续期只需主密码；它会轮换 capability，随后重启 MCP 并重新启动代理。

02 / AI 与受信执行器

先摘要，再查一条命令

monica commands --summary --json
monica commands grant --json

摘要用来定位命令。完整说明包含参数角色、前提条件、执行影响、信任边界与重试规则；不必每次读取整棵语法树。

  • 发现命令不等于获得执行权限。本地管理仍需人的授权；MCP 只提供当前 grant 允许的服务操作。
  • AI 提交公开参数。受信执行器通过 --secrets-stdin 注入秘密；密码和 Token 不进对话、参数或环境变量。
  • --json 不弹提示。读取 error.code 和 error.recovery，先恢复前提条件。
  • 授权到期请人续期；写入结果不确定时先核对，不换新的 request_id 盲目重试。

MCP 内从 monica_list_connections {} 开始，读取授权工具和范围。CLI 的 commands 是另一层接口。

推荐写法：connections / mcp-config / renew。旧命令 list / settings / refresh 和缩写继续可用；执行 JSON 的 command 标识保持原值。TUI 重载列表用 :reload，旧 :refresh 仍兼容。

Android API Key → 本地模型地址

用手机在 MDBX 中保存的 Key 代理 OpenAI 或 Anthropic 请求。模型客户端只拿到可撤销的本地 Key；原条目保持原生类型和身份。

monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant my-model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke
monica proxy-config my-model-client --output ./model-client.json
monica serve

OpenAI 本地地址默认 http://127.0.0.1:47831/v1；Anthropic 使用 --protocol anthropic，地址为 http://127.0.0.1:47831。让受信客户端读取输出文件的 base_url 和 api_key；文件应放在版本库外。

支持 JSON 与 SSE。一个本地 Key 选择一个上游，不转换协议。renew 后重新用 proxy-config --force 生成配置并让客户端重新载入。revoke 撤销授权；unbind 保留手机原条目。

serve --session-minutes 60 只延长进程上限；默认 Multi 仍要求 5 分钟内的新鲜认证，可能需更早重新解锁。模型授权不能调用通用服务 API 或 Issue 工具。
